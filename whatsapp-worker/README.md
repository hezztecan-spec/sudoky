# WhatsApp OTP Worker

Локальный воркер, который сидит на твоём ноуте и отправляет OTP через WhatsApp Web по команде удалённого бэка.

## Почему отдельный сервис

- Render Free засыпает, ~512 MB памяти, Chromium туда не влезет
- С серверного IP WhatsApp быстрее блокирует аккаунт
- Воркер инициирует соединение сам → не нужен публичный IP

## Первый запуск

```bash
cd whatsapp-worker
cp .env.example .env
# впиши BACKEND_WS и WORKER_SECRET (тот же, что у бэка на Render)
npm install
npm start
```

При первом запуске в консоли появится QR — отсканируй его в WhatsApp (Настройки → Связанные устройства → Привязать устройство). После этого сессия сохранится в `.wwebjs_auth/`.

## Фон

Чтобы воркер работал всегда — открой его в `tmux`/`screen` или настрой как `launchd` (Mac) / `systemd` (Linux). Без воркера сайт будет работать, но логин через OTP будет ломаться.
