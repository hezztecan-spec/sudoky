# Требования: Мультиигровая платформа «играй.лето»

## Контекст

Текущий проект — платформа судоку для ~8 знакомых. Расширяем до мультиигровой площадки с несколькими играми, сохраняя текущий бэкенд, авторизацию через WhatsApp и деплой на Render.

## Общие требования

### R1. Платформа
- Переименование: «sudoku.лето» → «играй.лето»
- Главная страница — хаб с карточками доступных игр
- Каждая игра — отдельный раздел с собственным рейтингом
- Общий профиль пользователя со статистикой по каждой игре
- Максимум ~8 пользователей, все знакомые

### R2. Авторизация
- Без изменений: вход по номеру телефона через WhatsApp OTP
- Один аккаунт на все игры

### R3. Мультиплеер
- Только с друзьями по ссылке-приглашению (без поиска случайного соперника)
- Real-time через существующий WebSocket

### R4. Рейтинги
- Отдельная таблица лидеров для каждой игры
- В профиле — сводная статистика по всем играм

## Игры

### G1. Судоку (уже есть)
- Без изменений, становится одной из игр в меню
- Свой рейтинг, ачивки, ежедневные задания

### G2. Крестики-нолики
- Классическое поле 3×3
- Игра с другом по ссылке
- Ход по очереди, real-time через WebSocket
- Победа / ничья / поражение
- Очки: +10 за победу, +3 за ничью, 0 за поражение
- Возможность реванша после окончания партии
- Статистика: побед / ничьих / поражений

### G3. Морской бой
- Классические правила: поле 10×10, корабли 4+3+3+2+2+2+1+1+1+1
- Расстановка кораблей перед началом (drag или тап)
- Ход по очереди: стреляешь → попал/мимо → если попал, ещё ход
- Real-time через WebSocket
- Очки: +30 за победу
- Статистика: побед / поражений / точность стрельбы

### G4. Слова (Wordle-подобная)
- Угадай слово из 5 букв за 6 попыток
- Одиночная игра, новое слово каждые 2 часа (как судоку)
- Подсветка: зелёный = правильная буква на месте, жёлтый = есть но не там, серый = нет
- Очки: зависят от количества попыток (6 → 10 pts, 1 → 100 pts)
- Русские слова
- Свой рейтинг

### G5. Реакция (Speed Test)
- Экран меняет цвет → нажми как можно быстрее
- 5 раундов, среднее время = результат
- Одиночная, можно играть сколько угодно раз
- Лучший результат в рейтинге
- Очки: чем быстрее среднее время, тем больше

### G6. Память (Memory Cards)
- Поле карточек рубашкой вверх (4×4 = 8 пар)
- Переворачиваешь по 2, ищешь пары
- Одиночная, на время
- Очки за скорость
- Свой рейтинг

## Технические требования

### T1. Архитектура
- Каждая игра — отдельный модуль (роут на бэке + страница на фронте)
- Общая таблица `game_results` для хранения результатов всех игр
- WebSocket: добавляем типы сообщений для каждой игры (ttt_move, bs_shot, etc.)

### T2. БД
- Новая таблица `game_sessions` (id, game_type, player1_id, player2_id, status, state_json, winner_id, created_at)
- Новая таблица `game_scores` (id, user_id, game_type, points, played_at)
- Существующие таблицы (users, puzzles, attempts, chat, achievements) — без изменений

### T3. Деплой
- Без изменений: Render (бэк + фронт + Postgres) + WhatsApp-воркер на ноуте
- Всё в одном репозитории
